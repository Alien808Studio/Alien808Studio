# Alien808 Studio

Il file `808_METODO_ALBUM.md` è il riferimento unico per scrivere le canzoni del primo album di Alien808.

- Leggilo all'inizio di ogni sessione, prima di scrivere o analizzare testi.
- Aggiornalo ogni volta che si trova la quadra: nuove regole di stile, brani approvati, analisi di testi di riferimento, cambi di tracklist. Aggiungi sempre una riga datata nel "Registro delle decisioni" e aggiorna la tabella "Stato dell'album".
- Dopo ogni aggiornamento fai commit e push, così il file resta salvato.
